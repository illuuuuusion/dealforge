Wie die Priorität entsteht – keine Black Box

Priorität = 25 + Frische × w + Kaufgrenze × w + Reparatur × w + Angebots-Median × w + Persönlich × w, begrenzt auf 0–100. Gewicht 0 schaltet einen Teil ab, 1 = Standard, bis 3.
